# AI-Based Crop Disease and Pest Scout 🌱

This project is an AI-powered system that detects crop diseases and pests from leaf images and provides treatment recommendations through an intelligent Q&A interface.

## Problem
Farmers often struggle to identify crop diseases early, leading to reduced yield and excessive pesticide usage.

## Solution
Our system uses a Convolutional Neural Network (CNN) to analyze crop leaf images and predict diseases. It also provides actionable guidance and answers farmer queries.

## Features
- Leaf image-based disease detection
- AI-powered treatment recommendations
- Question & Answer support
- Farmer-friendly interface

## Technologies Used
- Python
- TensorFlow / Keras
- Streamlit
- PlantVillage Dataset

## Future Scope
- Mobile app integration
- Voice & regional language support
- Weather-based disease alerts
- IoT sensor integration

## Impact
- Reduces crop loss
- Improves farming productivity
- Supports sustainable agriculture
